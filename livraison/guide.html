Mettre le site en ligne

1
Réservez le nom de domaine dpraxxam.com (s'il n'est pas déjà à vous) et un hébergement web simple (offre « mutualisée » avec cPanel ou FTP).
2
Décompressez DPR-AXXAM_site-web.zip et déposez tout son contenu (index.html, dossiers images et videos, etc.) dans le dossier public de l'hébergement (souvent public_html ou www).
3
Activez le certificat https (gratuit chez la plupart des hébergeurs : « Let's Encrypt »), puis ouvrez https://www.dpraxxam.com.
4
Facultatif : déclarez le site dans Google Search Console (le fichier sitemap.xml est fourni) et dans votre fiche Google Maps « Sarl dpr axxam ».

2. L'ERP Dolibarr (suite)

Installer sur un PC Windows

1
Installez Docker Desktop (docker.com), redémarrez le PC et lancez Docker Desktop.
2
Décompressez DPR-AXXAM_ERP-Dolibarr.zip dans C:\DPR-AXXAM\.
3
Double-cliquez sur demarrer.bat : le Bloc-notes s'ouvre, choisissez les 3 mots de passe, enregistrez, fermez, puis double-cliquez à nouveau sur demarrer.bat.
4
Après 2 à 3 minutes, le navigateur s'ouvre sur l'ERP. Identifiant admin, mot de passe choisi à l'étape 3. Les autres postes ouvrent http://ADRESSE-IP-DU-PC:8080.

Le premier jour

  1. Configuration › Société : ajoutez l'AI, le NIS et le logo (RC, NIF, capital et adresse sont déjà saisis).
  2. Configuration › Banques : ajoutez vos comptes bancaires.
  3. Produits : saisissez les prix de vente HT de B8, B12 et hourdis, puis le stock de départ (Corriger le stock).
  4. Utilisateurs : un compte par personne (commercial, magasinier, comptable), avec seulement les droits utiles.

Sauvegarder (chaque jour)

Double-clic sur sauvegarder.bat : un fichier sauvegardes\dolibarr-AAAA-MM-JJ_HHMM.sql est créé. Copiez-le sur une clé USB ou un disque externe. La restauration est décrite dans le README.md du dossier ERP.

Sécurité. Changez tous les mots de passe d'exemple. Si l'ERP doit être ouvert depuis Internet, faites-le installer derrière une adresse https par un technicien.
La comptabilité légale reste tenue dans PC Compta ; Dolibarr sert à la gestion quotidienne.

4. Points à vérifier

SujetÀ faire
ComptabilitéLe NIF et le RC de DPR AXXAM sont saisis sur le fournisseur SARL AXECHAN ELECTROME (FI121) ; le même NIF figure sur STATION GAMMA 4. Probable erreur de saisie à corriger.
ComptabilitéTrois fournisseurs étrangers sont nommés « A IDENTIFIER (PTI …) » (FE060, FE061, FE062) : à identifier.
ComptabilitéCertains tiers ont plusieurs codes (SARL DPR COMPANY : 5 codes ; SONELGAZ : 2). Ils restent séparés dans l'ERP, comme dans PC Compta.
ProduitsLes formats affichés (30×20×10, 30×20×15, 53×20×16) sont ceux de l'étude CNERIB : confirmez qu'ils sont les vôtres.
ChiffresLe −23 % vient d'une étude de la profession (CNERIB pour l'ABA, 2019), pas d'essais sur vos briques. Le simulateur donne des valeurs indicatives.
PhotosVérifiez vos droits sur les vues aériennes de la carrière (si elles viennent de Google Earth) et sur les visuels de l'ABA.
